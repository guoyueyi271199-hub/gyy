1 内容策划与文案输出
  • 独立负责「福瑞颐养」养老科普公众号从 0 到 1 整体运营，每周输出 5 篇原创推文，涵盖养老政策解读、健康科普、适老化产品推荐等内容，用直白语言降低阅读门槛。
  • 每日跟踪行业动态与用户关注趋势，快速响应当周热点完成选题策划与发文；筛选养老书籍撰写读书笔记与荐书内容嵌入推文，丰富内容维度。
  • 从 0 摸索账号定位与内容风格，建立选题库和内容素材库，形成稳定的排期与产出节奏。
  • 曾参与运营矩阵团文，累计发布内容 76 篇，单篇最高阅读量 10w+，团文转化率 4.5%；参与输出有赞小程序推文 747 篇。
2 KOL 资源与平台推广
  • 独立对接抖音、小红书等平台达人资源，参与商务谈判及资源置换，获取平台核心广告位及达人推荐位，提升品牌曝光量。
  • 根据平台用户调性策划产品推广方案，结合不同渠道特性制定差异化内容策略。
  • 所负责的达人合作渠道，2023 年销售额同比增长 96%，2024 上半年同比增长 202%；熟悉小红书、微博、抖音、公众号等平台的内容生态与推广方式。
3 活动策划与全流程执行
  • 每月配合营销节点独立输出活动方案，从需求提出到执行全程盯盘：技术侧拉会沟通工具开发需求，采购侧对接选品与成本测算，运营侧配置活动专题页。
  • 在后台独立配置优惠券、满减、秒杀等促销规则；针对重复性配置任务，让 AI 生成标准化配置 Excel 表格后批量导入后台，或调用 API 自动完成配置。
  • 使用平台自有小程序开发工具独立搭建活动专题页，完成页面布局、模块配置及上线前自测校验。
  • 亲自到线下站点布展，协调展位摆放与场地动线，观察用户从进店到买单的完整行动路径，找出影响体验的堵点并现场给出调整方案。
  • 以 7 月华大基因合作活动为例，单场活动 GMV 达 20 万；日常站点开业同步上线商城活动做流量承接。
4 数据复盘与流程提效
  • 用 Excel 拉透视表监控日销、核销率、转化率等核心指标；活动结束后完成数据复盘及财务对账，输出 PPT 分析报告，为下一轮策略调整提供依据。
  • 通过后台数据监控发现异常立即排查，形成「发现问题 → 定位原因 → 技术修复 → 客服兜底」的快速响应闭环。
  • 主动听到财务反馈采购流程混乱后，逐一访谈采购、财务、运营三方痛点，梳理从需求提报到报销的完整 SOP，用飞书多维表格搭建协同工具，减少来回沟通成本。
  • 日常用 Codex、Claude、Pi 等 AI 工具处理重复性数据整理、竞品调研框架搭建等工作。
