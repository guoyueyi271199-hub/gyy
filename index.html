CAPABILITIES

核心能力模块

1 产品、技术与 AI Agent 应用
  • 具备运营、产品、技术与 AI Agent 应用的复合能力，理解商城业务架构、前后端交互及代码逻辑，能够利用 AI Agent 将业务需求快速转化为产品方案、UI 界面及可交互页面，并完成商城、活动页、后台系统等场景的功能搭建与迭代。
  • 具备从需求分析、产品设计、交互设计到技术实现和运营落地的完整项目思维。
2 数据复盘与流程提效
  • 用 Excel 拉透视表监控日销、核销率、转化率等核心指标；活动结束后完成数据复盘及财务对账，输出 PPT 分析报告，为下一轮策略调整提供依据。
  • 通过后台数据监控发现异常立即排查，形成「发现问题 → 定位原因 → 技术修复 → 客服兜底」的快速响应闭环。
  • 主动听到财务反馈采购流程混乱后，逐一访谈采购、财务、运营三方痛点，梳理从需求提报到报销的完整 SOP，用飞书多维表格搭建协同工具，减少来回沟通成本。
  • 日常用 Codex、Claude、Pi 等 AI 工具处理重复性数据整理、竞品调研框架搭建等工作。
3 活动策划与全流程执行
  • 每月配合营销节点独立输出活动方案，从需求提出到执行全程盯盘：技术侧拉会沟通工具开发需求，采购侧对接选品与成本测算，运营侧配置活动专题页。
  • 在后台独立配置优惠券、满减、秒杀等促销规则；针对重复性配置任务，让 AI 生成标准化配置 Excel 表格后批量导入后台，或调用 API 自动完成配置。
  • 使用平台自有小程序开发工具独立搭建活动专题页，完成页面布局、模块配置及上线前自测校验。
  • 亲自到线下站点布展，协调展位摆放与场地动线，观察用户从进店到买单的完整行动路径，找出影响体验的堵点并现场给出调整方案。
  • 以 7 月华大基因合作活动为例，单场活动 GMV 达 20 万；日常站点开业同步上线商城活动做流量承接。
4 第三方平台商务协作
  • 独立对接饿了么、美团、淘鲜达等第三方 O2O 平台，开展商务协作，参与平台资源谈判，获取开机屏、首页 Banner、推送短信等核心资源位。
  • 赋能 KA 渠道：承担平台/KA 渠道销售费用的统计、分析及全流程管控，结合费比要求调整投放策略，推动营销费比同比下降 6%。
  • 所负责的平台合作渠道，2023 年销售额同比增长 96%，2024 上半年同比增长 202%。
5 内容策划与文案输出
  • 用搭建 Skill（可复用的 AI 工作流）的方式，为「福瑞颐养」养老科普公众号定制了一套推文发布自动化方案，把从信息检索到发布的完整内容生产链路，沉淀为可复用、可迭代的自动化工作流。
  • 打通「信息检索 → 平台直发」全链路：自动检索行业动态与热点，完成选题、文案生成与排版，随后直接连接公众号平台发布，全程无需跨工具来回搬运。
  • 将平台内容规范、选题偏好与发布流程固化进 Skill，输出稳定贴合公众号既有风格，并保持稳定的排期与产出节奏。
  • 结合日常使用反馈持续迭代 Skill，让选题、写作、发布各环节逐步贴合养老科普内容的传播特性，显著降低重复性人工操作。
